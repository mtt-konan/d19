# wl237 — wl218 slope quadratic curve boundary

日期：2026-06-22

## 1. 本轮目标

继续推进 `sum=A+B` 分支的核心引理：

```text
x,y 是正有理勾股斜率
x+y>1
P/Q 是有理平方
=> x=y
```

其中：

```text
P = 2x^2 + 2xy - 2x + y^2 - 2y + 1
Q = x^2 + 2xy - 2x + 2y^2 - 2y + 1.
```

普通话说：

```text
现在问题已经变成：
两个已经合格的直角三角形斜率 x,y，
能不能让这两个二次型只差一个平方倍数？
```

---

## 2. 代入勾股参数

参数化：

```text
x = (1-a^2)/(2a)
y = (1-b^2)/(2b)
```

其中正斜率对应：

```text
0<a,b<1.
```

代入后：

```text
P = Pn / (4a^2b^2)
Q = Qn / (4a^2b^2)
```

`Pn` 和 `Qn` 正是前几轮的 `A(t,u)`、`B(t,u)` 同一形状：

```text
Pn-Qn = (a-b)(a+b)(ab-1)(ab+1).
```

普通话说：

```text
把 x,y 再参数化以后，没有出现新的更简单问题。
它回到了同一个四次式。
```

这说明：

```text
x,y 二次型模型是目前最清楚的表述；
继续换回 a,b 只会回到旧的自相似 quartic。
```

---

## 3. `P = k^2 Q` 的判别式

写：

```text
Pn = k^2 Qn.
```

把它看成 `b` 的四次式，其判别式分解为：

```text
16 a^4 (a^2+1)^2
* L_-(a,k)^2
* L_+(a,k)^2
* R(a,k)
```

其中最后剩余 quartic 是：

```text
R(a,k)
= a^4k^4 -4a^4k^2 +4a^4
  +8a^3k^4 -24a^3k^2 +16a^3
  +18a^2k^4 -24a^2k^2 +8a^2
  -8ak^4 +24ak^2 -16a
  +k^4 -4k^2 +4.
```

并且：

```text
R(a,1) = (a^2+1)^2.
```

也就是说，中心线 `k=1` 是退化平方。

若令：

```text
K = k^2
```

则 `R` 是 `K` 的二次式，其判别式为：

```text
-64 a^2 (a^2+2a-1)^2.
```

普通话说：

```text
剩下的四次式不是随机的。
它对 K 的判别式是负的平方倍数。
这说明实数形状很受限，但还不能直接推出有理点只有中心线。
```

---

## 4. `s,d` 形式仍然最短

从 `x,y` 直接出发，令：

```text
s = x+y
d = x-y
```

则：

```text
P = (d^2 + 2ds + 5s^2 - 8s + 4)/4
Q = (d^2 - 2ds + 5s^2 - 8s + 4)/4.
```

若：

```text
P = k^2 Q
```

把它看成 `d` 的二次式，判别式分解为：

```text
-(k^2s-k^2-ks-s+1)(k^2s-k^2+ks-s+1).
```

普通话说：

```text
非中线就是 d!=0。
方程对 d 是二次的，判别式裂成两个线性因子。
下一步最可能从这里做局部符号。
```

## 6. 当前证明边界

可以安全说：

```text
1. 当前最短命题是 x,y 二次型引理；
2. 代入勾股参数会回到同一自相似 quartic；
3. s,d 形式给出最简单的二次判别式；
4. 小范围没有非中线反例。
```

不能说：

```text
sum=A+B 已证明。
倒数定理已证明。
quartic 已被完全求有理点。
```
