# wl112 — 固定直线模型：R_k 曲线、三距离很多、下一目标是 rs=k 归约

日期：2026-06-09

承接 wl111。本轮继续证明固定比例 `A=kB`，但不再试图用一句“筛子更强一点”解决，而是把剩余跨 orbit 问题写成可审计的曲线模型。

结论：

```text
跨 orbit 问题已经变成固定直线上的四有理距离问题。
这个问题至少是椭圆曲线级别，不是一个初等同余筛能直接杀掉的 conic。
最值得攻的下一条命题是：

若 r,s ∈ R_k 且 r+s=k+1 或其他 closure 目标，
是否可推出 rs=k？

一旦能推出 rs=k，就回到 reciprocal orbit，已由 wl110 排除。
```

---

## 1. R_k 的精确定义

固定：

```text
A = kB
r = N/B
```

真实 `N` 等价于：

```text
r^2 + 1   = square
r^2 + k^2 = square
```

记：

```text
R_k = { r in Q_{>0} : r^2+1 和 r^2+k^2 都是有理平方 }
```

一个 Harborth full-plane closure 在固定比例里变成：

```text
找 r,s ∈ R_k，使
r+s 或 |r-s| 等于 k+1 或 |k-1|。
```

wl110 已关掉：

```text
s = k/r
```

所以剩下的是：

```text
s 不等于 k/r 的跨 orbit closure。
```

---

## 2. R_k 本身是 genus-1 / 椭圆曲线级别

只看一个 `r`：

```text
r^2+1 = u^2
r^2+k^2 = v^2
```

第一条可以参数化：

```text
r = (t^2-1)/(2t),  t in Q, t>1
```

代入第二条：

```text
((t^2-1)/(2t))^2 + k^2 = v^2
```

清分母：

```text
(t^2-1)^2 + 4k^2 t^2 = (2tv)^2
```

也就是：

```text
w^2 = t^4 + (4k^2-2)t^2 + 1
```

这是一条四次曲线。一般情况下它是 genus 1，可以转成椭圆曲线。

普通话版本：

```text
“一个 N 同时对 A 和 B 勾股”已经不是圆锥，而是一条椭圆曲线。
两个 N 再满足 closure，就是在两份这条曲线上加一条线性关系。
```

这解释了为什么：

```text
纯 residue 筛不够；
简单奇偶/gcd 不太可能一下证明完；
后续可能需要 Mordell-Weil sieve / Chabauty / 递降。
```

## 3. 固定直线中“三距离点”很多，不能当杀招

如果只要求点在固定直线 `x=1` 上，到同一条竖边的两个顶点距离有理，即：

```text
y^2 + 1 是平方
(T-y)^2 + 1 是平方
```

这已经经常有解。小核查例子：

```text
T=5,  y=209/120
```

因为：

```text
(209/120)^2 + 1 = (241/120)^2
(5-209/120)^2 + 1 = (409/120)^2
```

还有：

```text
T=6,  y=21/20
T=8,  y=8/15
T=14, y=667/156
```

这些不是四距离反例，只说明：

```text
固定直线上的三距离/两端距离现象并不少。
真正困难在于同时满足另一条竖边的两个距离。
```

因此下面这种证明路线是错的：

```text
先证明固定直线同一边两个距离不能同时有理。
```

它已经被小例子否掉。

## 4. closure 后的乘积变量 p=rs

若有 sum closure：

```text
r+s = T
```

其中 `T` 是：

```text
k+1 或 |k-1|
```

令：

```text
p = rs
```

则：

```text
r^2+s^2 = T^2 - 2p
```

如果 `r^2+1, s^2+1` 都是平方，那么两者乘积也是平方：

```text
(r^2+1)(s^2+1)
= r^2s^2 + r^2+s^2 + 1
= p^2 - 2p + T^2 + 1
```

所以必要条件：

```text
p^2 - 2p + T^2 + 1 是有理平方。
```

同理，如果 `r^2+k^2, s^2+k^2` 都是平方：

```text
(r^2+k^2)(s^2+k^2)
= p^2 - 2k^2p + k^2T^2 + k^4
```

所以还有必要条件：

```text
p^2 - 2k^2p + k^2T^2 + k^4 是有理平方。
```

再加上 `r,s` 有理，二次方程：

```text
X^2 - TX + p = 0
```

必须有有理根，即：

```text
T^2 - 4p 是有理平方。
```

于是 sum closure 给出一个较小的必要条件系统：

```text
T^2 - 4p                                     是有理平方
p^2 - 2p + T^2 + 1                           是有理平方
p^2 - 2k^2p + k^2T^2 + k^4                   是有理平方
```

注意它只是必要条件，不是充分条件，因为：

```text
(r^2+1)(s^2+1) 是平方
不代表 r^2+1 和 s^2+1 各自都是平方。
```

这个坑已经用小枚举看到了：会放进很多假阳性，例如 `r=s=T/2` 这类边界点。

## 5. 最想证明的 rs=k 归约

在同一个 reciprocal orbit 中：

```text
s = k/r
```

等价于：

```text
rs = k
```

所以如果能证明：

```text
r,s ∈ R_k 且 closure
=> rs = k
```

那么固定比例 `A=kB` 就会被完全关闭：

```text
closure => rs=k => s=k/r
=> 同 reciprocal orbit
=> wl110 已证明不可能。
```

这条命题目前还没有证明，但它是非常清楚的 theorem target。

普通话版本：

```text
我们现在想证明：
两个能参与 closure 的 N/B，如果真的存在，
它们其实只能是一对镜像。
而镜像已经证明闭不上。
```

### 为什么它不像空想

小数据里常见的自然成对 ratio 都满足：

```text
rs = k
```

例如：

```text
k=7:   (12/5)*(35/12) = 7
k=10:  (35/12)*(24/7) = 10
k=14:  (15/8)*(112/15) = 14
```

同时，乘积变量的必要条件里也经常冒出边界坏点：

```text
r=1, s=k
```

它同样满足：

```text
rs=k
```

但因为：

```text
1^2+1 = 2
k^2+1 夹在 k^2 和 (k+1)^2 中间
```

不是真实 `R_k` 点。

这提示 `rs=k` 可能是 closure 代数里的天然边界，而不是偶然。

### 当前困难

乘积必要条件太弱：

```text
它只能保证两个平方条件的乘积是平方，
不能保证每一项分别是平方。
```

所以不能直接用 `p=rs` 的三个平方条件完成证明。

要推进，需要加入“单项平方”的信息。可能的方式：

```text
1. 在 R_k 椭圆曲线上研究 involution r -> k/r。
2. 把 closure 线 r+s=T 看作 E_k × E_k 上的切片。
3. 证明该切片只落在 anti-diagonal / reciprocal graph 上。
4. 或者对 p 系统加 squareclass 条件，排掉乘积假阳性。
```

## 6. 对差分 closure 的同样写法

若：

```text
|r-s| = T
```

可设：

```text
s = r + T
```

或者把较大的减较小的叫 `T`。类似地令：

```text
p = rs
```

则：

```text
r+s = sqrt(T^2+4p)
```

因此差分分支也可以被压成：

```text
T^2 + 4p 是有理平方
```

再配合：

```text
(r^2+1)(s^2+1)
(r^2+k^2)(s^2+k^2)
```

得到类似的乘积必要条件。

但同样要小心：

```text
乘积为平方 != 两项分别为平方。
```

所以差分分支也需要 squareclass / 椭圆曲线层面的处理。

## 7. 更强一点的 squareclass 观察

设：

```text
X = r^2 + 1
Y = s^2 + 1
Z = r^2 + k^2
W = s^2 + k^2
```

真实 closure 要求：

```text
X,Y,Z,W 全都是有理平方。
```

乘积变量 `p=rs` 只用了：

```text
XY 是平方
ZW 是平方
```

这会丢掉信息。可以再看两个交叉乘积：

```text
XW = (r^2+1)(s^2+k^2)
YZ = (s^2+1)(r^2+k^2)
```

如果 `X,Y,Z,W` 全是平方，那么当然：

```text
XY, XW, YZ, ZW
```

也全是平方。

反过来，在 squareclass 群 `Q*/Q*2` 里，如果：

```text
XY, XW, YZ, ZW 都是平方
```

则：

```text
[X]=[Y]=[Z]=[W]
```

也就是说，四个因子会被迫落在同一个 squareclass。

但这仍然不够，因为共同 squareclass 可能是非平凡的：

```text
X = d * square
Y = d * square
Z = d * square
W = d * square
```

其中 `d` 不一定是平方。真实 `R_k` 要求的是：

```text
d = 1 in Q*/Q*2
```

所以乘积路线缺的最后一块正是：

```text
证明共同 squareclass 必须平凡。
```

这句话和 2-descent 很像。它也解释了为什么简单乘积条件会产生假阳性：

```text
它只看到“同一个 squareclass”，没看到“这个 squareclass 是不是 1”。
```

下一步如果继续走 `p=rs`，应当引入：

```text
squareclass variable d
```

而不是只枚举 `p`。

## 8. 一个直接指向 rs=k 的恒等式

对 sum closure：

```text
r+s = T
p = rs
```

上面两个乘积平方条件分别记为：

```text
A_p = p^2 - 2p + T^2 + 1
B_p = p^2 - 2k^2p + k^2T^2 + k^4
```

也就是：

```text
A_p = (r^2+1)(s^2+1)
B_p = (r^2+k^2)(s^2+k^2)
```

它们满足一个非常整齐的恒等式：

```text
B_p - k^2 A_p = (k^2 - 1)(k^2 - p^2)
```

这个恒等式不依赖 `T=k+1` 还是 `T=k-1`，只要 `r+s=T` 就成立。

为什么它重要：

```text
目标 rs=k 等价于 p=k。
而恒等式右边正好含有 k^2-p^2。
```

如果能用平方条件证明左边不能以别的方式成为两个平方量的差，就会推出：

```text
p = k
```

然后回到 wl110 的 reciprocal orbit 排除。

当前还差的一步：

```text
A_p 与 B_p 是平方只说明两个平方之间的差固定为 (k^2-1)(k^2-p^2)。
平方差本身可以有很多表示，所以还需要 p-adic valuation、descent、
或 squareclass d 的额外约束。
```

但这是目前最具体的代数抓手，比“继续扫 k,B”更接近证明。

## 9. 下一步建议

最有效的下一步不是继续扩大整数搜索，而是做一个小型理论/计算混合模块：

```text
fixed_line_curve.py
```

它不应该直接宣称证明，而是提供可审计对象：

```text
1. 把 R_k 四次曲线 w^2=t^4+(4k^2-2)t^2+1 输出成 Sage/pari 可读模型。
2. 对 closure target T=k±1 建立 E_k×E_k 的线性切片。
3. 枚举小 k 的跨 orbit rational points，验证是否都被 rs=k 或坏边界吸收。
4. 若某 k 的曲线 rank 低，再尝试人工列尽。
```

当前主线结论：

```text
A=kB 还没证明全灭。
但剩余问题已经非常精确：
证明 closure 切片只可能给 rs=k；
而 rs=k 分支已经由 reciprocal orbit 命题排除。
```
