# wl119 — `sum=A+B` 的弱 `p` 模型不够强

日期：2026-06-09

承接 wl118。

本轮检查这个子目标：

```text
T = λ + 1
A_p, B_p, D 都是有理平方
能不能推出 p = λ？
```

结论：

```text
不能。
```

而且很快能找到非中心线反例。它不是原问题反例，因为 `r,s` 不是真 `R_λ` 成员；但它足够说明：

```text
只用 A_p, B_p, D 这三个平方条件证明 p=λ，路线不成立。
```

---

## 1. 弱模型

sum closure：

```text
r+s = T
p = rs
```

本轮先看：

```text
T = λ + 1
```

wl118 写出：

```text
A_p = p^2 - 2p + T^2 + 1
B_p = p^2 - 2λ^2p + λ^2T^2 + λ^4
D   = T^2 - 4p
```

如果 `r,s∈R_λ` 且 `r+s=T`，那么：

```text
A_p 是有理平方
B_p 是有理平方
D 是有理平方
```

其中 `D` 保证 `r,s` 是有理根。

问题是反过来是否够强：

```text
A_p, B_p, D 是平方
=> p=λ？
```

答案是否。

---

## 2. 非中心线弱反例

取：

```text
λ = 535/161
r = 14/23
s = 26/7
```

则：

```text
r+s = 14/23 + 26/7
    = 535/161 + 1
    = λ + 1
```

所以满足 `sum=A+B` 的 closure target。

乘积：

```text
p = rs = 52/23
```

但：

```text
p ≠ λ
```

具体：

```text
52/23 ≠ 535/161
```

计算三个弱条件：

```text
D = (λ+1)^2 - 4p = 250000/25921 = (500/161)^2
```

```text
A_p = p^2 - 2p + (λ+1)^2 + 1
    = 525625/25921
    = (725/161)^2
```

```text
B_p = p^2 - 2λ^2p + λ^2(λ+1)^2 + λ^4
    = 190463289241/671898241
    = (436421/25921)^2
```

所以：

```text
A_p, B_p, D 都是有理平方，
但 p≠λ。
```

这直接否定“弱 p 模型推出 p=λ”。

---

## 3. 为什么它不是原问题反例

检查 `R_λ` membership：

```text
r^2 + 1
= (14/23)^2 + 1
= 725/529
```

`725/529` 不是有理平方。

另一个：

```text
s^2 + 1
= (26/7)^2 + 1
= 725/49
```

`725/49` 也不是有理平方。

所以：

```text
r∉R_λ
s∉R_λ
```

这个例子只是假装通过乘积层条件，没有通过真实单项平方条件。

普通话说：

```text
两个数乘起来是平方，
不代表两个数各自都是平方。
```

这里就是这个坑的有理比例版本。

```text

```

这不是为了证明某个定理，而是为了防止后续证明把弱模型误当成真模型。

## 5. 路线调整

wl118 的下一步曾建议先攻：

```text
A_p, B_p, D 是平方
=> p=λ
```

现在这条被反例关闭。

新的正确目标必须保留更强条件：

```text
r^2+1
s^2+1
r^2+λ^2
s^2+λ^2
```

分别都是有理平方。

等价地，不能只看两个乘积：

```text
(r^2+1)(s^2+1)
(r^2+λ^2)(s^2+λ^2)
```

而要追踪它们如何分裂成两个平方。

下一步可以改成：

```text
固定 T=λ+1。
用 r+s=T 把 s=T-r。
直接研究四个单项：

r^2+1
(T-r)^2+1
r^2+λ^2
(T-r)^2+λ^2

是否能同时为有理平方。
```

这回不要急着压成 `p` 一个变量。

```text

```

`p` 是好坐标，但不是完整坐标。

真正要保留的是：

```text

```
