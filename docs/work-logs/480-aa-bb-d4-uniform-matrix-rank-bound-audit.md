# AA+BB D4 Uniform Matrix Rank Bound Audit

## Question

After the complete `d`-coordinate local rows are solved through `wl479`, do
the rows force a uniform complete Selmer upper bound of dimension `2` for

```text
E_L: Y^2 = (X+p)*(X^2 - 4*q)?
```

The inputs combined here are:

- pure odd rows `wl475`-`wl477`,
- dyadic row strata from `wl478`,
- real sign row from `wl473`,
- D0 product relation

```text
d_minus_p*d_pos_2sqrt_q*d_neg_2sqrt_q = 1 in Q*/Q*2,
```

- D3 rational two-torsion baseline from `wl474`.

## Result

The solved rows do not by themselves force a uniform complete Selmer upper
bound of dimension `2`.

The D4 ledger reduces the question to a parameter-dependent `F2` character
matrix, denoted

```text
M_tail.
```

The missing theorem is a uniform full-rank statement for this matrix. Without
that rank theorem, no complete Selmer upper bound is proved.

## Row Generator Ledger

The D0 product relation and solved complete `d` rows put the global generators
into the following patterns:

```text

w_ell           = (1, ell, ell)        for odd ell | sqrt_q
w_2             = (1, 2, 2)            only in the balanced dyadic stratum
```

Write

```text
omega_L       = # odd primes dividing L
omega_T       = # odd primes dividing T
omega_sqrt_q  = # odd primes dividing sqrt_q
epsilon_balanced_2 =
  1 if v2(T)=v2(L)+1, equivalently v2(sqrt_q) is odd,
  0 otherwise.
```

Before applying the remaining residual-character matrix, the row ledger has
formal dimension

```text
1 + omega_L + omega_T + omega_sqrt_q + epsilon_balanced_2.
```

The visible D3 torsion baseline has dimension `2`, generated by

```text
tau_minus
tau_sqrt_q = product_{ell|sqrt_q} w_ell
             times w_2 when v2(sqrt_q) is odd.
```

## Surviving Tail Formula

After quotienting the visible torsion baseline, the unresolved algebraic tail
has dimension

```text
dim(tail)
  = omega_L + omega_T + omega_sqrt_q + epsilon_balanced_2
    - 1 - rank(M_tail).
```

Thus a dimension-`2` upper bound would require

```text
rank(M_tail)
  = omega_L + omega_T + omega_sqrt_q + epsilon_balanced_2 - 1
```

uniformly for all primitive AA+BB inputs.

## What Is M_tail?

`M_tail` is the `F2` matrix of residual local characters left by the solved
rows:

```text
odd ell | L:
  local class(d_minus_p) = local class(d_pos_2sqrt_q)

odd ell | T:
  local class(d_minus_p) = local class(d_neg_2sqrt_q)

odd ell | sqrt_q:
  local class(d_pos_2sqrt_q) = local class(d_neg_2sqrt_q)

ell = 2:
  the dyadic aggregate class constraints from wl478.
```

Its entries are Legendre/Hilbert character values of the other selected
support generators at the active local row, plus the dyadic residue characters.
Those values depend on the actual primitive AA+BB input. The completed D2 row
ledger identifies this matrix, but does not prove that it has the required
uniform rank.
