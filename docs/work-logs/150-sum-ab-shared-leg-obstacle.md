# wl150 — `sum=A+B` shared-leg obstacle

日期：2026-06-09

## 1. 本轮问题

wl149 说明小模数不能直接把：

```text
both-pass
```

压成：

```text
nu-mv = 0
```

这轮换角度看：

```text
共享腿 N 同时配出多个勾股三角形，本身是不是稀有？
```

普通话说：

```text
如果同一个 N 本来就很难配两个勾股三角形，
那也许能直接证明 both-pass 不行。
```

结果：

```text
不行。
共享腿双勾股本身很常见。
真正的难点是 P=bc、Q=ad 这两个边必须来自同两组 Euclid 参数。
```

---

## 2. 普通 shared-leg 很常见

扫描小范围整数：

```text
N^2 + P^2 = H^2
```

发现很多 `N` 有多组 `P`。

例如：

```text
N=8:
  P=6,15

N=12:
  P=5,9,16,35

N=15:
  P=8,20,36,112

N=24:
  P=7,10,18,32,45,70,143
```

普通话说：

```text
同一条腿能配多个勾股三角形，这一点并不罕见。
所以不能只靠“共享 N”推出矛盾。
```

---

## 3. 固定 N=105 的例子

wl142 的 near-miss 样例：

```text
N = 105
P = 360 通过
Q = 420 失败
```

但 `N=105` 本身有很多合法勾股搭配：

```text
P = 36,56,88,100,140,208,252,360,608,784,...
```

其中：

```text
105^2 + 360^2 = 375^2
```

但：

```text
420
```

不在这串合法 `P` 里。

普通话说：

```text
失败不是因为 105 很难配勾股边。
105 能配很多。
失败是因为 Euclid 结构强行给出了 420，而 420 不在合法列表里。
```

---

## 4. near-miss 小范围观察

对 same orientation 小范围扫：

```text
2 <= m,u < 35
primitive parity
```

观察到很多三通过 near-miss。

典型：

```text
odd/odd:
  (m,n)=(4,1), (u,v)=(7,2)
  N=105
  P=360 通过
  Q=420 失败

even/even:
  (m,n)=(4,1), (u,v)=(4,3)
  N=224
  P=360 通过
  Q=56 失败
```

也有一些失败的 Q 离另一个合法勾股边很近，但差值没有明显统一规律。

普通话说：

```text
near-miss 确实很多；
但“离合法边差多少”看起来不是一个简单的一维规律。
```

---

## 5. 当前判断

shared-leg 参数化是必要的，但不充分。

不能只证明：

```text
同一个 N 有两套勾股参数很难。
```

因为这本身不难。

必须使用额外结构：

```text
P = bc
Q = ad
P-Q = ±2(mu+nv)(nu-mv)
P+Q = 2(mu-nv)(mv+nu)
```

普通话说：

```text
真正绑住问题的是 P 和 Q 的来源：
它们不是随便两条勾股边，
而是由同两组 Euclid 参数交叉乘出来的。
```

---

## 6. 能说什么，不能说什么

可以说：

```text
shared-leg double-Pythagorean 本身不是矛盾。
后续证明必须用 P=bc, Q=ad 的交叉乘结构。
```

不能说：

```text
same orientation 有反例。
near-miss 差值有明显规律。
共享腿路线失败。
```

---

## 7. 下一步

下一步建议不要继续看普通 shared-leg。

应该直接研究：

```text
P = bc
Q = ad
```

带来的整除约束。

具体可以尝试：

```text
1. 对 P=bc 和 Q=ad 分别取 gcd：
   gcd(P,Q), gcd(b,a), gcd(c,d)

2. 利用 primitive Euclid legs：
   gcd(a,b)=1
   gcd(c,d)=1

3. 看 both-pass 参数中的 g1,g2 是否必须吸收某些因子。

4. 若 nu-mv != 0，尝试从 P-Q 的因子中构造更小参数。
```

普通话说：

```text
下一步从“共享腿”转向“交叉乘的整除结构”。
这才是可能递降的地方。
```
