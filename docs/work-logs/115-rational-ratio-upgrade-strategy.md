# wl115 — 从整数固定比例 k 升级到有理比例 λ：外推价值审查

日期：2026-06-09

本轮先暂停“继续证明整数 `A=kB`”，改做战略审查：

```text
就算证明所有整数 k，能不能继续推广到整个空间？
```

结论：

```text
单独证明 A=kB, k∈Z_{>0}，外推价值有限。
真正有价值的是把模型升级到有理比例：

λ = A/B ∈ Q_{>0}
```

原因很简单：

```text
如果正方形四顶点距离全有理，那么点坐标本身也是有理。
归一化后，横向两段距离 A/B 就是有理数，而不一定是整数。
```

所以整数 `k` 只能覆盖稀疏切片；有理 `λ` 才接近覆盖整个候选空间。

---

## 1. 有理比例模型

把 `B` 归一化为 1：

```text
λ = A/B
r = N/B
```

定义：

```text
R_λ = { r in Q_{>0} :
        r^2 + 1   是有理平方，
        r^2 + λ^2 是有理平方 }
```

full-plane closure 变成：

```text
r+s   = λ+1
r+s   = |λ-1|
|r-s| = λ+1
|r-s| = |λ-1|
```

这和整数 `k` 版完全同形，只是：

```text
k 被 λ 替换，λ 允许任意正有理数。
```

---

## 2. reciprocal 对称仍然成立

若：

```text
r ∈ R_λ
```

即：

```text
r^2+1   = u^2
r^2+λ^2 = v^2
```

则：

```text
λ/r ∈ R_λ
```

因为：

```text
(λ/r)^2 + 1   = (r^2+λ^2)/r^2 = (v/r)^2
(λ/r)^2 + λ^2 = λ^2(r^2+1)/r^2 = (λu/r)^2
```

所以核心 involution：

```text
r -> λ/r
```

可以无损推广。

这是好消息。

---

## 3. 但整数 k 证明不能原样搬过来

wl110 里关闭同一个 reciprocal orbit 时，部分步骤用了：

```text
k^2+1 不可能是有理平方
```

对整数 `k`，这是真的，因为：

```text
k^2 < k^2+1 < (k+1)^2
```

但对有理 `λ`，这句话不成立。例如：

```text
λ = 3/4
λ^2 + 1 = 25/16 = (5/4)^2
```

所以：

```text
整数 k 的夹逼证明不能直接推广到有理 λ。
```

这就是“有理空间稠密”在代数里的具体表现：整数上的不可能，换成有理数后可能立即失效。

边界：这不等于同 orbit 在有理 `λ` 下真的能 closure。比如 `r=λ` 还要满足：

```text
r^2+λ^2 = 2λ^2 是有理平方
```

这会要求 `sqrt(2)` 有理，仍然不可能。

所以同 orbit 排除可能仍成立，但证明理由必须重写。

---

## 4. 有理 λ 下同 orbit 的四个关系

同 orbit 设：

```text
s = λ/r
```

四种 closure 关系变成二次方程。

### 4.1 r+λ/r=λ+1

```text
r + λ/r = λ+1
=> (r-1)(r-λ)=0
```

所以：

```text
r=1 或 r=λ
```

若 `r=1`：

```text
r^2+1 = 2
```

不是有理平方。

若 `r=λ`：

```text
r^2+λ^2 = 2λ^2
```

也不是有理平方，因为 `sqrt(2)` 不是有理数。

所以这一支仍可排除。

### 4.2 |r-λ/r|=|λ-1|

类似地会给：

```text
r=1 或 r=λ
```

同样被 `2` / `2λ^2` 排除。

### 4.3 r+λ/r=|λ-1|

整数 `k` 时这支靠判别式很快排掉。

有理 `λ` 时判别式：

```text
(λ-1)^2 - 4λ = λ^2 - 6λ + 1
```

可能是有理平方。例如 `λ=6` 时为 `1`。

但对应根 `r=2,3` 并不在 `R_6`：

```text
2^2+1=5
3^2+1=10
```

所以“二次方程有有理根”不够，还必须使用完整 `R_λ` 条件。

### 4.4 |r-λ/r|=λ+1

判别式：

```text
λ^2 + 6λ + 1
```

在有理 `λ` 下也可能是平方。例如 `λ=3/2` 时为 `49/4`。

但对应正根 `r=3` 不在 `R_{3/2}`：

```text
3^2+1=10
```

所以这支也不能靠判别式结束，需要完整平方条件。

---

## 5. 战略判断

整数 `k` 分支的价值有两层：

```text
低价值：证明所有整数 k 无解。
高价值：找到一个不依赖整数性的结构，能推广到有理 λ。
```

目前真正值得追的是高价值版本：

```text
Rational-Ratio Reciprocal Theorem:

For every λ∈Q_{>0}, if r∈R_λ and λ/r participates in any full-plane
closure relation with r, then impossible.
```

更进一步是：

```text
Rational-Ratio Translation Theorem:

For every λ∈Q_{>0}, if r,s∈R_λ satisfy one of the full-plane closure
relations, then s=λ/r.
```

如果第二条成立，那么：

```text
closure => reciprocal orbit
=> reciprocal theorem 排除
=> 覆盖所有有理比例 λ
```

这才真正接近覆盖整个空间。

## 6. 下一步该怎么做

不要继续优先证明整数 `k`。

应该先把 wl112-wl114 全部升级成 `λ` 版：

```text
1. R_λ 曲线模型。
2. reciprocal involution r -> λ/r。
3. closure 平移/反射 r -> T-r, r -> r+T。
4. 平方矩形模型：

   (M-T)^2 + 4,
   (M+T)^2 + 4,
   (M-T)^2 + 4λ^2,
   (M+T)^2 + 4λ^2

   全是有理平方。

5. p=rs 模型：

   A_p = p^2 - 2p + T^2 + 1
   B_p = p^2 - 2λ^2p + λ^2T^2 + λ^4

   并检查恒等式：

   B_p - λ^2 A_p = (λ^2-1)(λ^2-p^2)
```

若这些都成立，下一步 theorem target 应改写为：

```text
对任意 λ∈Q_{>0}，
closure 平移交点只能来自 reciprocal involution。
```

这条若能证明，才真正有机会升维到整个问题。

## 7. 普通话总结

证明整数 `A=kB` 像是在证明“某些斜率的直线不行”。

但真正候选点的斜率/比例是有理数，不只整数。

所以：

```text
整数 k 证明本身不是终点；
它只是试验场。
```

下一步必须问：

```text
这个证明是否能把 k 换成任意有理 λ？
```

如果能，就值得继续。

如果不能，整数固定比例证明即使完成，也大概率只是一个孤立分支，对全局证明帮助有限。
