# 全平面闭合关系对照表

## 变量映射

```
原始 pair:        (A, B)
有理比例:         λ = A/B
Concordant 整数:  N₁, N₂
有理比例形式:     r = N₁/B,  s = N₂/B
```

## 四种全平面闭合关系

普通话说：这里的“闭合”只要求两条距离的和或差，能够拼出 `A+B` 或
`|A-B|` 这两个目标长度之一。它不要求对应的点一定落在正方形内部。
`N₁+N₂=A+B` 是最像“正方形内部”的那一支，但全平面定理还包括另外三支。

### N层面表述（用于concordant整数）

GEN-CLOSURE充要条件（wl093-094）:
```
{N₁+N₂, |N₁−N₂|} ∩ {A+B, |A−B|} ≠ ∅
```

展开为四种情况：
1. N₁ + N₂ = A + B
2. N₁ + N₂ = |A − B|
3. |N₁ − N₂| = A + B
4. |N₁ − N₂| = |A − B|

### r,s层面表述（用于R_λ倒数定理）

除以B得到有理比例形式（wl218）:
```
{r+s, |r−s|} ∩ {λ+1, |λ−1|} ≠ ∅
```

这条是全平面条件：它不假设点在单位正方形内部，也不允许只用
`r+s = λ+1` 代替整个闭合条件。

展开为四种情况：
1. **sum=A+B**:    `r + s = λ + 1`       (对应 N₁+N₂=A+B)
2. **sum=|A-B|**:  `r + s = |λ − 1|`     (对应 N₁+N₂=|A−B|)
3. **diff=A+B**:   `|r − s| = λ + 1`     (对应 |N₁−N₂|=A+B)
4. **diff=|A-B|**: `|r − s| = |λ − 1|`   (对应 |N₁−N₂|=|A−B|)

### 代码常量映射

在 `src/rational_distance/concordant/rational_ratio.py`:
```python
REL_SUM_AB = "sum=A+B"      # r + s = λ + 1
REL_SUM_DIFF = "sum=|A-B|"  # r + s = |λ − 1|
REL_DIFF_AB = "diff=A+B"    # |r − s| = λ + 1
REL_DIFF_DIFF = "diff=|A-B|" # |r − s| = |λ − 1|
```

## 特殊情况

当 `λ = 1` (即 A = B) 时：
- `|λ − 1| = 0`
- `sum=|A-B|` 和 `diff=|A-B|` 的目标值为0
- 代码中这两种关系会被跳过（zero target直接拒绝）

## 倒数对定义

对于 `(r, s) ∈ R_λ × R_λ`:
- **倒数对**: `r · s = λ`  (等价于 `s = λ/r`)
- **R_λ倒数定理**: 若 `(r,s)` 满足上述任一闭合关系且都是真R_λ成员，则必为倒数对
