# Minimal Task Anchor

Use this template for a newly authorized scoped task. Keep the root anchor
short; link to detailed evidence instead of copying history into it.

```markdown
# <Task title>

- Status: active | complete | paused
- Updated: YYYY-MM-DD
- Task id: <unique-id>
- Authorization: <user or selected-task authorization>
- Goal: <one precise objective>
- Scope: <object, quantifiers, and allowed changes>
- Protected behavior: <stable files, claims, and branches to preserve>
- Current obligation: <exact next proof, audit, or implementation step>
- Completion criterion: <accepted result or precise unresolved boundary>
- Validation: <focused checks and evidence links>
- Result/next step: <fill when complete or paused>
```

Add inputs, exceptional branches, rollback, or external execution details only
when they affect a decision. Existing anchors may retain legacy execution
metadata for provenance; new anchors should omit fields that do not change the
task's scope, safety, or verification.
